# 软件验证记录

日期：2026-10-13。目标：WHEELTEC C10B / STM32F103RCT6。

## 已通过

- STM32Cube GNU GCC 14.3.1 编译 Debug 和 Release，均生成 ELF / HEX / BIN，无编译警告。
- 控制模拟：目标 1 圈、3 圈和持续模式；上电/复位、按钮消抖、八路转向、255 个非空检测图案、横线计圈、误触发、丢线故障、通信失效及使能禁止停车。
- UART 状态模拟：全部 256 个字节、四种极性/探头顺序组合、接收超时、迟到及非请求数据、长帧拒绝、错误标志、32 位 tick 回绕。
- 接口审计：板级引脚无重叠，SWD 保留，.ioc 资源匹配，CMake/调试目标/芯片宏/链接脚本匹配，高密度启动文件的 UART4 向量正确。
- 软件 I²C 的 .ioc 输出类型与已安装 CubeMX F103xC GPIO 数据库核对：输出开漏。
- 固件二进制初始栈地址及 UART4 向量检查。
- 对照修改前哈希：stm32-item 的 89 个源文件、car-for2 的 100 个源文件均未改变。
- 源码差异无尾随空白错误。生成的 map 文件包含工具链自身输出的尾随空白，未修改生成格式。

## USER / LED1 更新

新增每次 USER 有效按下切换 LED1（PC2）亮灭。上电和 Reset 熄灭，25 ms 消抖，长按只切换一次，灰度故障或禁止行驶时仍有效。LED1 状态通过 `app_diagnostics.user_led_on` 查看。

三种圈数模式的控制模拟、按键切换/长按/复位/故障测试、协议测试和接口审计均通过；Debug 与 Release 编译通过。当前电脑未检测到 ST-Link，本次 LED1 新版本尚未写入控制板。

此前基础 C10B 固件已经成功烧录并校验；其运行诊断确认 MPU6050 身份为 0x68，灰度仍无有效应答，电机输出为零。先前诊断快照对应基础固件，不能作为 LED1 新版本的实测记录。
