## 已纠正的问题

| 项目 | 迁移前 | 当前工程 |
| --- | --- | --- |
| MCU / 封装 | F103C8T6 / LQFP48 | F103RCT6 / LQFP64 |
| 芯片宏 / 启动文件 | STM32F103xB / startup_stm32f103xb.s | STM32F103xE / startup_stm32f103xe.s，包含 UART4 向量 |
| Flash / SRAM | 64 KB / 20 KB | 256 KB / 48 KB，芯片具体型号按板级资料 |
| 灰度输入 | PA0～PA4 五路 GPIO | PC10/PC11 UART4 八路状态 |
| 电机驱动 | 外接 TB6612，双 PWM + 方向 + STBY | 板载两片 AT8236，TIM3 四路 PWM；无 STBY |
| USER | PB5 低电平有效 | PA0 高电平有效；PB5 留给 OLED |
| LED | PC13 输出 | PC2 为 USER 切换 LED1、PC3 为故障灯，均低电平点亮；PC13 为使能输入 |
| MPU6050 | 未配置 | PB14/PB15 软件 I²C，0x68 身份检查 |
| 灰度故障 | 无串口有效性判断 | 禁止无数据启动，接收故障/超时停车，需要按键重启 |
| 工程元数据 | C8 .ioc / 调试目标 | 同步为 RCT6、对应引脚和链接脚本 |

## 外接接口针序

编号按原理图，插接方向以实物丝印和插座编号为准。

| 接口 | 针号 | C10B 信号 | 对端 |
| --- | --- | --- | --- |
| CN6 / OpenMV / UART4 | 1 | 5V | 幻尔 5V |
| CN6 | 2 | GND | 幻尔 GND |
| CN6 | 3 | PC10 / UART4_TX | 幻尔 RX |
| CN6 | 4 | PC11 / UART4_RX | 幻尔 TX |
| H6 / MPU6050 | 1 | 5V | 带板载稳压的 GY-521 模块 VCC；裸芯片不能直接接 5V |
| H6 | 2 | GND | MPU 模块 GND |
| H6 | 3 | PB14 | SCL，开漏并由模块拉到 3V3 |
| H6 | 4 | PB15 | SDA，开漏并由模块拉到 3V3 |
| H6 | 5～7 | 原理图无连接 | 不使用 |
| H6 | 8 | PB9 | MPU 中断预留；本工程不使用 |
| H10 / SWD | 1 | 3V3 | 正规 ST-Link VTref/VAPP 参考；确认下载器定义 |
| H10 | 2 | PA14 | SWCLK |
| H10 | 3 | GND | GND |
| H10 | 4 | PA13 | SWDIO |

用户记录中的模块 TX→C11、RX→C10 与上述 UART4 交叉接法一致。本轮没有用仪器验证线缆端到端对应、信号电平或模块端 5V。

## 板载电机接口

| 通道 / 接口 | 针号 | 电路连接 |
| --- | --- | --- |
| B / U5 / CN2 | 1、6 | BO1、BO2 电机两端 |
| B / CN2 | 2、5 | GND、编码器 5V |
| B / CN2 | 3、4 | PC6、PC7，TIM8_CH1/CH2 编码器预留 |
| B 输入 | — | PB0 IN1 / TIM3_CH3；PB1 IN2 / TIM3_CH4 |
| A / U6 / CN3 | 1、6 | AO1、AO2 电机两端 |
| A / CN3 | 2、5 | GND、编码器 5V |
| A / CN3 | 3、4 | PB6、PB7，TIM4_CH1/CH2 编码器预留 |
| A 输入 | — | PA6 IN1 / TIM3_CH1；PA7 IN2 / TIM3_CH2 |

软件默认 A 为左轮、B 为右轮、IN1 的 PWM 为正转。这是可调整的车体安装假设，原理图只能确认 A/B 通道连接，不能证明实车左/右及正转。必须架空车轮确认后设置 `CAR_LEFT_IS_MOTOR_A` 和两个 `FORWARD_IN1` 参数。

AT8236：IN1=PWM、IN2=0 和 IN1=0、IN2=PWM 分别控制两个方向；双输入零为滑行/休眠。当前停车不使用双输入高的刹车模式。
